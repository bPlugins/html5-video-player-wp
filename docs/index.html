HTML5 Video Player — Introduction

HTML5 Video Player is a flexible, fully responsive video player plugin for WordPress, trusted by 30,000+ websites. It lets you embed self-hosted MP4, WebM and OGG files — as well as YouTube, Vimeo and Amazon S3 videos — anywhere on your site using shortcodes, Gutenberg blocks or Elementor, with no code required.

What You Get

Every player you create is an independent, reusable item. You configure it once in the WordPress dashboard, then place it on any post, page or widget with its shortcode or block. The player adapts seamlessly to all devices and screen sizes and works across all major browsers.

  • Multiple video sources — media library, CDN URL, YouTube, Vimeo, and AWS S3.
  • Full control customization — show or hide every button on the control bar.
  • Skins & brand colors — seven skins plus color options to match your site. Pro
  • Quality switcher & subtitles — YouTube-style resolution switching and multilingual captions. Pro
  • Protection — password protection, role-based access and watermarking. Pro
  • Monetization & marketing — Google VAST ads, email capture with CRM integrations, end screens with calls to action. Pro
  • Playlists — modern playlist layouts with search, keyboard navigation and autoplay-next. Pro
  • SEO ready — schema markup so Google can index your videos.

Installation & Activation

HTML5 Video Player installs like any standard WordPress plugin. Choose whichever method suits you.

Install from the WordPress Dashboard

  1. In your WordPress admin, go to Plugins → Add New Plugin.
  2. Search for “HTML5 Video Player” by bPlugins.
  3. Click Install Now, then Activate.

Install by Uploading a ZIP

  1. Download the plugin ZIP file (Pro users download it from their bPlugins account).
  2. Go to Plugins → Add New Plugin → Upload Plugin and choose the ZIP file.
  3. Click Install Now, then Activate.

Alternatively, upload the extracted plugin folder to /wp-content/plugins/ over FTP and activate it from the Plugins menu.

After Activation

A new Html5 Video Player menu appears in the WordPress admin sidebar with the following items:

Quick Start: Your First Player

You can go from a video file to a published, fully working player in under five minutes. Here’s the complete flow.

Step 1 — Pick Your Editor (First Run Only)

Right after activation the plugin asks how you want to build players — the Classic Metabox Editor (a tabbed settings panel) or the Gutenberg Editor (block-based, with live preview). Both produce the same shortcode; pick whichever feels familiar. See Choosing Your Editor for the full comparison — you can change this anytime in settings.

Step 2 — Create the Player

  1. Go to Html5 Video Player → Add New in your WordPress dashboard.
  2. Give the player a name at the top — for example “View From A Blue Moon”. The name is only for you; visitors never see it.
  3. Choose a Video Source — Library/CDN, YouTube, Vimeo, or AWS S3 — and paste your video URL, or pick a file from the media library. You’ll find this in the Media tab (Classic editor) or the Media panel of the block sidebar (Gutenberg editor).
  4. Optionally set a Video Thumbnail (the poster image shown before playback starts).
  5. Click Publish / Update to save.

Step 3 — Copy the Shortcode

In the Classic editor the shortcode bar sits right below the player name — click it to copy. In the Gutenberg editor, copy it from the All Players list:

[html5_video id='1453']

The id points at this specific player, so every setting you change later automatically follows the shortcode wherever it is used.

Step 4 — Place It on a Page

  1. Edit any post or page in the block editor.
  2. Add a Shortcode block and paste the shortcode in — or use the dedicated HTML5 Video Player Gutenberg block and pick your player from a dropdown.
  3. Publish the page. Your video is live.

To print a player from a theme template, use PHP:

<?php echo do_shortcode("[html5_video id='1453']"); ?>

Where to Go Next

  • Change the player’s look in Skins & Controls.
  • Add resolutions and captions in Quality Switcher & Subtitles.
  • Fine-tune autoplay, loop and sticky behavior in Playback Settings.
  • Restrict who can watch in Password Protection & Roles.
Tip

Each player’s configuration is scoped to that one player, so you can build completely different setups side by side — a locked course video here, an autoplaying background loop there.

Choosing Your Editor

There are two ways to create a player and its shortcode: the Classic Metabox Editor — a tabbed settings panel — and the Gutenberg Editor — visual, block-based editing with a live preview. Both produce exactly the same [html5_video id='…'] shortcode; the only difference is how you configure the player.

The First-Run Chooser

Right after activation the plugin shows an “HTML5 Video Player is ready” screen asking how you want to build your players:

  1. Review the two cards — Classic Editor and Gutenberg Editor. Each has an Eye/Preview button that shows exactly how the editing experience will look.
  2. Select the one you prefer (Gutenberg is pre-selected by default).
  3. Click Continue. You’re taken to the plugin dashboard, and every new player now opens in your chosen editor.
Note

This is a preference, not a commitment — you can change it anytime in the plugin settings (see below).

Switching Editors Later

Go to Html5 Video Player → Settings → Shortcode & Tools → Shortcode/Player and toggle Enable Gutenberg Shortcode Generator:

  • On — new players open in the Gutenberg editor.
  • Off — new players open in the Classic metabox editor.
Players remember their editor

Each player keeps opening in the editor it was created with, even if you switch the preference later. A player built in Gutenberg always reopens in Gutenberg; a player built in the Classic metabox always reopens there. The setting only affects players you create from that point on.

How to Set Each Source

Library or CDN Source

  1. Select the Library or CDN source pill in the widget’s Settings section.
  2. Use Select Video to pick a file from the media library, or paste a direct file URL into the video id or url field.
  3. The Elementor canvas re-renders the player live — no need to preview the page.
  1. Select the Library or CDN source pill.
  2. Pick a file from the WordPress media library, or paste a direct file URL (MP4, WebM, OGG, .m3u8 or .mpd) into Source URL.
  3. The canvas preview reloads with the new source right away. Click Update — the change applies everywhere the player’s shortcode is embedded.

YouTube

  1. Select the Youtube pill.
  2. Paste the regular watch URL — for example https://www.youtube.com/watch?v=XXXXXXXX — into Source URL.
  3. Click Update. The plugin wraps the YouTube stream in its own skinned controls.

Vimeo

Works exactly like YouTube — select the Vimeo pill and paste the video’s URL into Source URL.

Not in the Elementor widget

The widget has no S3 file browser. Configure the S3 source on a saved player (Classic or Gutenberg), then place that player’s shortcode in an Elementor Shortcode widget.

AWS S3 Pro

  1. Add your S3 credentials — Key ID, Access Key, Bucket and Region — under Html5 Video Player → Settings → AWS S3.
  2. Back in the player’s Media tabMedia panel, select AWS S3 File Manager and click Choose From AWS S3 Storage.
  3. Browse the bucket and pick your video file.

Video Thumbnail (Poster Image)

The Video Thumbnail field sets the still frame viewers see before pressing play. Pick an image from the media library or paste an image URL.

For YouTube and Vimeo sources the thumbnail acts as a backup: the platform’s own thumbnail loads first, and yours steps in if that fails.

Related option: Show Thumbnail When Video Pause (in the Settings tabSettings panel) brings the poster back whenever the viewer pauses, so the player looks deliberate instead of frozen mid-frame.

Custom Download URL Pro

By default the download button (if enabled) serves the streaming file. Turn on Custom Download URL to point the download button at a different file — for example a lower-resolution cut, a ZIP archive, or a version hosted elsewhere.

Adaptive Streams (HLS & DASH)

Point the source URL at an .m3u8 (HLS) or .mpd (DASH) manifest and the plugin loads the appropriate streaming engine automatically. The plugin can also hide/encode the stream URL so it isn’t exposed in the page source.

Converting SRT to VTT

If your captions are in .srt format, you don’t need an external tool — the plugin has a built-in converter:

  1. Go to Html5 Video Player → Settings → Shortcode & Tools → Convert .srt to .vtt.
  2. Drag your .srt files onto the drop area, or click it to browse. You can drop several at once.
  3. Check the preview. If the converter had to repair anything — timestamps missing milliseconds, unsupported styling tags — it lists exactly what it changed.
  4. Choose Save to Media Library to store the .vtt straight away, or Download .vtt to keep a copy.
  5. Attach the .vtt to the player’s subtitle track — the Media tabSubtitle/Caption panel.

Conversion happens in your browser, so the .srt file is never uploaded to your server. That also sidesteps WordPress’ upload rules, which block .srt files by default.

Accessibility

Multiple subtitle tracks make videos accessible and multilingual. Combined with the keyboard-operable Plyr controls, the player is accessibility-ready out of the box.

Skins & Controls

The Settings tabpanel and the preset editor are where the player starts to look like yours — pick a skin, choose exactly which buttons appear, and set your brand color.

Not available in the Elementor widget

The widget has no Skin control — it always renders the default control bar. To use a different skin on an Elementor page, set the skin on a saved player (Gutenberg or Classic) and place its [html5_video id='…'] shortcode in an Elementor Shortcode widget. Individual control buttons can be toggled in the widget — see below.

Skins Pro

  1. Edit the player, select the player block, and open the Presets panel in the right-hand sidebar.
  2. Click Add New Preset (or edit an existing preset) to open the full-screen preset editor.
  3. Choose your skin from the Skin selector above the preview on the right — the preview redraws instantly, so you can compare all seven without closing the modal.
  4. Click Create Preset / Update Preset, then apply that preset to the block.
Why the skin lives in the preset editor

On the free version a Skin dropdown appears in the block’s Settings panel as a Pro preview. Once Pro is active, skins are chosen in the preset editor instead — so one saved preset can carry the same look across every player on the site.

  1. Edit the player and open the Settings tab.
  2. Pick a skin from the Skin picker at the top of the tab — each option shows a thumbnail of its control-bar layout, so you can compare them at a glance.
  3. Click Update, then refresh the page embedding the player to see the new look.

Presets

In Gutenberg, presets are more than a shortcut — the Presets panel opens a full-screen editor where you build a complete player look with a live preview beside you. Several options live only here.

  1. Select the player block and open the Presets panel (the first panel in the sidebar).
  2. Click Add New Preset Pro, or click an existing preset to edit it.
  3. Give it a Preset Name, then work through the sections in the left column: Controls, Settings, Watermark, Style, End Screen and Email Capture. (Call To Action and Action Bar are marked Upcoming and aren’t functional yet.)

Presets keep a whole video library consistent without repeating setup work. There are two separate systems, and they don’t share data:

  • The Gutenberg preset editor (above) — a named, reusable bundle covering controls, settings, watermark, style, end screen, email capture and skin, built with a live preview.
  • Settings → Player → Preset — site-wide playback defaults (Repeat, Muted, Auto Play, Player Width, Seek Time and more) used by the Classic Shortcode Generator.

Playback Settings

The lower half of the Settings tabpanel is a run of playback switches that control how the video behaves — from autoplay to sticky mode.

Partly available in the Elementor widget

The widget’s Settings section carries the common playback options — autoplay, muted, loop, sticky, preload and seek time. Options it doesn’t expose (Save State, Disable Pause, Show Thumbnail on Pause, Custom Play Button, VAST) need a saved player embedded through an Elementor Shortcode widget.

Behavior Toggles

All of these live in the player’s Settings tabpanel, below the controls grid. Flip what you need and click Update — the change applies everywhere the shortcode is embedded.

Popup Player

The Popup tabpaneloption opens your video in a lightbox modal instead of embedding it inline — a tidy way to keep a landing page clean while still offering the full video. Pro

Enabling the Popup

  1. Select the HTML5 Video Player widget and open its Settings section.
  2. Switch Enable Popup on.
  3. Set the trigger text/button options that appear, then preview the page.
  1. Open the player’s Popup tabpanel.
  2. Switch Enable Popup on and save.
  3. Where the shortcode is placed, visitors now see a trigger instead of the inline player; clicking it launches the video in a distraction-free overlay.

Pairing It with a Button

A common pattern is a call-to-action button that launches the video. Set Trigger Type to Button, then pick one of two routes with the Use Existing Button toggle.

Let the plugin add the button (toggle off)

  1. Leave Use Existing Button off.
  2. Set Button Text, alignment and styling. A ready-made trigger button is placed next to the player — in Gutenberg it is locked so it can’t be deleted or moved by accident.

Use a button you already have (toggle on)

  1. Switch Use Existing Button on.
  2. Put the button’s CSS class in Selector (Classic) or Button Class (Gutenberg). A bare class name is enough — watch-video is read as .watch-video — and #watch-video or [data-popup] work too.
  3. The button must already exist on the same page as the player. If the selector matches several elements, only the first one becomes clickable.

Either way, clicking the button opens the player in the overlay; closing it returns the visitor to the page exactly where they were.

Tip

Popup options are also available in the Classic Shortcode Generator and the Gutenberg block settings, so you can enable the lightbox no matter how you embed the player.

Who Can See This Video?

Narrow the audience further with three options:

  • Everyone — no restriction (default).
  • Logged-in Users — only authenticated users can watch.
  • Logged-out Users — only visitors who are not signed in (useful for promo content aimed at non-members).

  3. The protection rule kicks in and your custom message appears instead of the player.
Tip

Shortcode Reference

Everything the plugin renders can be placed with a shortcode — in posts, pages, widgets, or theme templates via do_shortcode().

Saved Player: [html5_video]

Renders a player you created under Html5 Video Player → Add New — whether it was built with the Classic metabox editor or the Gutenberg editor, the shortcode is identical:

[html5_video id='1453']
Attribute Description
id The player’s ID — shown next to each player under All Players and on the edit screen.

Quick Player: [video_player]

Renders a player directly from a URL, with no saved player needed. Ideal for one-off embeds:

[video_player src="https://example.com/video.mp4"]

With attributes:

[video_player src="https://example.com/video.mp4" autoplay="false" muted="true" preload="metadata" width="500px" skin="modern" controls="play-large, progress, current-time, mute, volume, settings, fullscreen"]
Attribute Values Description
src URL Direct link to the video file (required).
controls comma-separated list Which controls to render: play-large, restart, rewind, play, fast-forward, progress, current-time, mute, volume, captions, settings, pip, airplay, download, fullscreen.
autoplay true / false Start playback on load (browsers require muted="true").
muted true / false Start with sound off.
preload auto / metadata / none How much of the video loads up front.
width e.g. 500px Player width.
reset_on_end true / false Rewind to the start when playback finishes.
skin Pro default / stacked / modern / floating-pill / classic-minimal / stacked-dual-row / modern-mobile-stack Control-bar skin for this embed — see Skins & Controls. Unrecognized values fall back to default.

Site-wide defaults for this shortcode live under Html5 Video Player → Quick Player.

Playlist: [video_playlist] Pro

[video_playlist id='1234']
Attribute Description
id The playlist’s ID from Html5 Video Player → Playlists.

Common Issues

Most support questions come down to a handful of predictable causes. Check these first.

Autoplay Isn’t Working

Modern browsers (Chrome, Safari, Edge) only allow autoplay when the video is explicitly muted. Enable Muted together with Auto Play in the player’s Settings tab. Also note that enabling a Watermark disables autoplay for that player.

The End Screen Never Appears

Switch Reset On End and Repeat off. If the player rewinds or loops at the end, the end screen can’t display. See End Screen.

Subtitles Won’t Upload or Display

The player only accepts .vtt files. If your captions are .srt, convert them with the built-in SRT→VTT converter in Settings → Shortcode & Tools, then re-upload.

Download or PIP Button Missing

For YouTube and Vimeo sources, the Download and Picture-in-Picture buttons are unavailable — the platforms don’t permit them. For self-hosted files, check that the buttons are enabled in Control buttons and Components.

Quality Switcher Shows the Wrong Resolution

When using the quality switcher, the main Source URL should be the 720p version of the video; the alternates you add (576, 1080, …) are offered in the settings gear.

Conflict with Another Video Plugin

If another plugin or your theme also handles the WordPress [video] shortcode, disable the plugin’s [video] override in Settings → Shortcode & Tools to avoid double-rendering.

Protected Video Shows for Everyone (or No One)

Test in an incognito window — your admin session may be satisfying the rule. Check the Who Can See This Video selection and the Allowed User Roles checklist. See Password Protection & Roles.

Theme or Plugin Conflicts

The plugin is compatible with most themes and plugins, but third-party conflicts can happen. To diagnose: switch temporarily to a default theme (e.g. Twenty Twenty-Four) and disable other plugins one at a time. If you find a conflict, report it to support — compatibility fixes ship regularly.

Reporting Security Issues

Please report security bugs through the Patchstack Vulnerability Disclosure Program, which handles verification, CVE assignment and developer notification.

Self-hosted MP4, WebM and OGG files; HLS (.m3u8) and DASH (.mpd) streams; plus YouTube, Vimeo and AWS S3 sources.

Unlimited. There are no limits on players, playlists, or embeds.
